# 首板接力筛选与竞价复核评审

日期：2026-11-24。评审参考脚本 `gemini-code-1795480063936.py`，衔接[盛剑型首板方案](盛剑型首板机会发现与筛选_20261123.md)。本次只做方案评审、历史抽样和只读接口验证；未修改生产策略、未配置推送。

## 一、参考代码能用什么

保留它的涨停池字段和「盘后母池 → 次日确认」框架，不采用固定阈值全量相交作为正式筛选。

| 参考代码 | 裁定 |
|---|---|
| 行业涨停数 Top3 | 字段是供应商的行业，不是当日涨停归因。行业宽度做背景；用有时点的细分题材做同链分组，按首板新增数、1/2/3 板构成、晋级分母、失败封板和价量变化判断梯队。剔除目标股自身的贡献。强孤立高标可以是风向标，但不能当题材扩散；新方向也不要求首日已有完整梯队。 |
| 流通市值 20–60 亿、股价 5–35 元、换手 5–18% | 可当研究分组，不作统一门槛。同板块、同高度、相近容量比较换手，另算相对自身的活跃度。60 日先看价格区间、EMA20/60、上方压力距离和累计扩张；没有持仓级数据，不把成交分布称为实际筹码。盛剑首板换手 1.65%，二板约 1.34%，原门槛两天都不留。 |
| 首封不晚于 10 点、开板最多一次、封流比至少 2% | 首封可作为优先验证项，末封及回封稳定性要同看。区分 `收盘封单/流通市值`、`收盘封单/当天成交额`，不同量纲的含义不能互换。封单是挂单，不是已成交承接。确认一字必须看日线或盘中过程；低换手不是一字的定义。 |
| 连板数降序，其次首封时间 | 会让 2/3 板压过刚出现的首板。分开「新点火 / 1 进 2」「接力 / 2 进 3」「高位 3 板以上观察」；前两栏各自排，不为填榜而推荐。 |
| 龙虎榜和席位 | 附件 `check_lhb_risk()` 只查上榜及净额，没有读取席位或执行过滤。已有 `top_list/top_inst` 优先，AKShare 席位接口只补查已上榜标的。用「两家及以上」作一支预注册对照；同时记录去重后的席位数、对应买入额/同榜买入前五总额、对应净额/全日成交额。按上榜原因与披露窗口归档，不叠加单日与累计榜。营业部名称不代表特定交易人，也不证明游资撤退、散户接盘。 |
| 时间和异常处理 | 不能仅靠 `zfill(6)` 比较。比如 `10:00:00` 会被字符串比较误排在 `100000` 之后，而空值字符串填充后也可能通过。兼容 `93000`、`093000`、`09:30:00`，转时分秒，校验时间及日期。区分源缺失、部分到齐、成功空池、未上榜；失败不能当无机会，也不自动放宽阈值。 |

## 二、已有样本的反查

使用 2026-10-22 至 11-10 的 13 个可核验交易日，对照时点有效的本地盘后事实和参考涨停表，取两边都标为收盘首板、含有效首末封/换手的 612 个主板事件。用[近半年逆查底表](../results/research/hot_outcome_reverse/20261120/events.csv)标记随后是否走成三板：

|---|---:|---:|
| 无过滤 | 32/612 | — |
| 收盘价 5–35 元 | 19/424 | 13/188 |
| 换手 5–18% | 19/317 | 13/295 |

这不是完整脚本回测：没有替代或假填历史流通市值、参考行业前三和封流比门槛，没有竞价、龙虎榜席位效果，也未评估实际成交。四条相交的晋级比例约 6.8%，但只保留 32 个晋级结果中的 3 个；首封时间值得先验证，不足以定固定阈值。统计集中于少量日期，不能把同一天多个同题材股票当作独立重复验证。

## 三、日常分层

1. **D 日盘后提名。** 15:30 可以启动收集，不假设参考封板、龙虎榜、公告均已更新。按数据到齐状态发初版、留发布时间，晚到证据另存版本。股级输入复用现有 EOD 的 U/Z、盘后归因与首末封等字段，题材输出首板是否新增、晋级率、掉队率、同链成员反应。分别给出新点火与接力名单、反证和次日复核要求。
2. **D+1 开盘集合竞价只作确认。** 冻结昨晚的阶段、结构价格边界、预期、对照组及公告版本。按 `竞价实际成交价 / 可比昨收 - 1` 和 `竞价实际成交金额（元）/ 昨日全天成交金额（元）` 计算。将高开 2%–5%、金额占比 5%–10% 记为待验证组合，用同日同梯队的全样本、不同板块/市场环境比较；另对比个股平时竞价活跃度。昨日已强、今日更强叫延续，不把所有高开写作弱转强。没有证实时不用日线开盘价、首分钟成交额、虚拟匹配量替代。金额占比可能因为昨日一字缩量而虚高，必须记录分母。
3. **观察提醒与可成交分开。** 9:25 确认的是已经结束的集合竞价，脚本取得结果后不能把该次撮合价当作可拿到的成交价。可用才报告实际收到时间、涨幅、金额、同梯队比较和风险；逾时或过期数据记为缺失。不凭竞价结果下单，不自动安排推送。日线一字交易有成交量，也不能据此假定自己的委托成交；开板后另判断价格、承接和风险边界。
4. **公告和监管独立复核。** 「常规异常波动」「否认核心业务或重大传闻」「风险提示」「监管工作函／重点监控／停牌」按原文、可知时点、严重度和适用期分列。澄清或亏损后的高开可记录市场反应，不提高执行权限；研究分支把待人工核实的监管事件列为仅观察，不修改原系统交易门。龙虎榜席位不作单独否决。

## 四、接入顺序和验收

- **先做盘后影子排名**：复用 `eod_review`、`limit_theme`、`first_board_watch` 和首板的价格结构。比较原榜、只按板数/首封的基线、加入梯队与局部结构的候选榜；按 1 进 2、2 进 3 分开报告 Top3/5 覆盖、晋级、冲高回落、一字/未成交及风险命中。加入席位过滤前，先报告有效龙虎榜的覆盖与漏选损失。
- **数据门已实测**：用当前配置在历史日期分别查询 Tushare `stk_auction`、`stk_auction_o`，均返回 `40203`。前者官方提供当日 09:26–09:29 拉取窗口，后者官方标明盘后 20:00 更新，不能提供晨间提醒。目前没有验证通过的竞价数据源，不能用代理指标给出已确认信号。授权或替代数据源到位后，首先核对金额单位、返回时效、观察池覆盖和实际缺失率，再接提醒。
- **最后才验证参数与执行**：同一日、同一板块/板数分组比较原阈值、相对排名及不启用该因子的对照；按日期切分，冻结候选版后再做样本外验证。若研究实际机会，从收到信号后的可成交价格计，单列跳空、一字无成交证据与退出受阻，不用当日最低价。
