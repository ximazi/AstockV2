## 启动与使用

固定使用8068端口，只保留一个服务。更新后在原启动窗口按Ctrl+C停止，再执行同一条命令，不另开8069、8070、8071实例。

```powershell
cd D:\AICode\Astock
python -X utf8 mainwave_visual_app.py --host 127.0.0.1 --port 8068
```

访问 `http://127.0.0.1:8068/`。左侧可按批次筛选或搜索代码、名称、题材。点击股票查看现有单股全周期分析。

进入栏目时分析日期恢复为最新生产日报日期；修改顶部日期后点“分析”可查看其他截面。归档快照的行情日和记录日不会随分析日期改写，也不能作为当时生产命中证明。当前生命周期和执行许可仍由原分析接口判断。

## 数据与验证

- `mainwave_engine/selection_board.json`：版本化研究归档，不依赖可能被清理的results目录。
- `mainwave_engine/selection_board.py`：只读合并与分组。`GET /api/selections`不扫描股票、不计算全市场、不生成订单。
- 新批次按复核先后追加到batches，保留真实记录日、行情日、唯一id和报告来源。相同symbol自动合并，最新一次入选决定展示分组，旧快照保留。
- 分组为CORE_WATCH、CONDITIONAL_WATCH、WATCH、RESERVE。每日扫描不会自动清空归档，也不会把旧观察升级成今日推荐。
- 本功能不改变daily_full、生产状态机、持仓或风控规则，无需新增每日执行步骤。

验证命令：`python -m unittest mainwave_engine.test_selection_board`。

如果页面缺少栏目，应同时检查磁盘中的注册文件、后端`/api/selections`接口和模板的`selectionSource`入口；单纯换端口无法修复代码缺失。
