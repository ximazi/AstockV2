# ETF固定池周期跟踪

版本：`etf_cycle_v1_20260906`。这是原全周期分析台的独立栏目，不启动第二套服务、不下单、不改持仓。

## 入口与每日执行

浏览器 `http://127.0.0.1:8068/` 左侧 **ETF周期**。固定10只ETF，支持强趋势、参与价值、正偏离过热、负偏离超调分类，总览和单只K线详情。阶段有背景色和逐日延续记录。

日常仍执行 `daily_full.ps1`，新增 STEP 3 自动更新这10只并出报告。`-SkipUpdate` 时ETF也只读缓存。没有额外定时任务，持续跟踪随每次每日流程运行。

```powershell
# 单独更新ETF，不运行股票扫描或旧ETF交易引擎
python -m mainwave_engine.etf_tracker --date 2026-09-04 --refresh

# 指定历史日期，用本地完整缓存重建
python -m mainwave_engine.etf_tracker --date 2026-08-31

# 数据源修订或需要重新拉取已缓存日期
python -m mainwave_engine.etf_tracker --date 2026-09-04 --force-refresh

# 手动启动可视化，仍只用8068；已有服务时不再启动
python -X utf8 mainwave_visual_app.py --host 127.0.0.1 --port 8068
```

不传日期默认当天，按上交所交易日历定位到最近交易日。回看未生成的日期，界面显示最近较早报告及实际日期，不伪装成该日结论。需要精确回看时先运行指定日期重建命令。

## 数据与口径

- 注册表 `mainwave_engine/etf_watchlist.json`：保留用户8月31日选样及题材；未自行替换成员，未独立复核全市场同类冠军。题材归类不代表持仓完全去重，科技ETF之间仍可能高度重叠。
- 价格采用 Tushare `fund_daily`；成交额千元乘1000转为元，日均成交额统一按最近20个交易日计算。原选样表未注明均额窗口，不将其当作同窗口验证。
- `fund_adj` 严格按日期配对。复权价格 = 原始价格 × 当日因子 / 分析日因子。今年涨幅从上年12月31日精确收盘算起，缺基准则显示未知；不是净值收益率。
- 历史计算先截断日期，再算指标/生命周期。因子缺失拒绝生成，份额拆分不制造暴跌。缓存可能包含数据源事后修订，历史报告属于当前数据重建而非不可修订的当时已知行情库。
- `fund_nav` 同时限制净值日期与公告日期不晚于分析日，只和净值同日原始收盘价配对。跨境基金滞后配对值不当作当前溢价，也不是实时IOPV折溢价。
- 固定10只，日线增量补最近10个自然日；每个新分析日补全这10只的历史因子和净值。成功的相同日期刷新直接用缓存，失败项目下次重试；强制刷新可重取修订数据。
- 页面GET只读已生成JSON，不联网、不扫描、不更新持仓。旧 `etf/main.py` 的交易流程没有接入。

接口依据：[ETF日线](https://tushare.pro/document/2?doc_id=127)、[复权因子](https://tushare.pro/document/2?doc_id=199)、[基金净值](https://tushare.pro/document/2?doc_id=119)。

## 三个独立判断

1. **连续周期**：复用 `phase_events.classify_frame`、`stock_lifecycle.replay`、`price_cycle_setups`。本轮启动后保留周期记忆，不因一天整理重新称作吸筹。派发风险是量价警告，不是证实ETF主力出货。
2. **强弱与偏离**：价格 > EMA20 > EMA60，且两条均线较5日前上行才标强趋势。偏离既给百分比，也给 `(价格-EMA20)/ATR20` 与自身此前252日分位。ATR使用此前20日均值，不把今天大跌导致的波动放大当作正常。
3. **参与价值**：行情最新、20日均额≥0.5亿是硬门槛。强趋势、距EMA20不超过1.5ATR、最近5日曾回踩EMA20且当前站上、周期风险解除，才进入“优先研究”。只有趋势与位置满足则“趋势内候选”。没有符合标的可以为空，不强凑买入名单。

正偏离≥2ATR且自身分位≥90：过热不追；负偏离≤-2ATR且分位≤10：超调待确认。负尾部未达2ATR不自动触发超调。企稳观察为收盘高于EMA10且当日复权低点高于前5日最低点，不等于底部确认。正/负偏离阈值和1.5ATR、2%折溢价警戒线均为**占位待校准**，没有ETF胜率/潜在收益背书。

优先级冲突时，行情/流动性限制优先，随后过热/超调风险，再看周期风险和趋势内位置。强趋势标记独立保留，所以可以同时“强趋势”和“风险未解除”。本模块不修改股票生产状态机，不将A股环境直接套在日本或美国资产上。尚未接入对应底层指数实时环境、实时IOPV、份额净申购数据，交易前仍需复核这些条件及账户风险预算。

## 输出与验证

- `data/etf_tracker/`：日历、10只日线/因子/净值及刷新状态。
- `results/etf_tracker/YYYYMMDD/`：`daily_report.md`、`watchlist.csv`、`summary.json`、10份单只JSON。
- 同日重跑覆盖该日快照，不重复追加；其他日期保留。首次已生成2026-08-31至2026-09-04五个交易日，单只图展示最近250个交易日连续轨迹。
- ETF专项测试覆盖复权拆分/分红、历史截断、生命周期前缀稳定、净值公告滞后、流动性、数据异常、缓存幂等及GET离线，另运行现有生命周期/筛选榜单等回归测试。
