# 每日复盘 V2：分析方法与双层报告规范

版本：2.0。适用对象：用户已有A股主线/强势交易研究系统。本文是设计与展示规范，不是经过盈利验证的策略升级。

## 一、这次反思究竟改什么

问题不是“万邦涨了，所以以后一定买更强的小票”。问题是在已知证据不足的情况下，把药明的成交容量提升成短线交易优先级，同时对万邦采用更严格的缺数和风险标准，并擅自只保留趋势回踩路线。

需要同时避免两种偏差：一端是为了显得稳妥，把强势机会换成未经比较的容量标的；另一端是看到一次结果，就取消风险边界、追逐当天涨幅排名。

### 六项修订

|原缺陷|V2要求|可验收结果|
|---|---|---|
|交易目标漂移|报告先冻结目标、持有期限、允许模式和风险预算|替代标的必须在相同任务下比较；不同期限不直接排总名次|
|容量替代机会|角色、容量、相对强弱、结构、模式和可执行性分列|不再从“成交额最大”直接导出“最该买”|
|风险误杀机会|先识别机会，再定位风险影响：排除、等待、更小风险预算或补证|高换手不是全局否决；未成熟模式仍只能研究|
|证据门槛不对称|两侧相同必需字段；缺失为UNKNOWN，不是FAIL|不拒绝A的未知却给B豁免|
|只等回踩|强势确认、趋势回踩、尾盘隔夜都运行适用性检查|不满足一个模式只否定该模式，不全局删除股票|
|用结果维护/推翻故事|保留前向记录、同时间行情、可执行性与成交证据|一次反馈登记流程问题，不宣称已验证收益改进|

## 二、三个判断对象必须分开

1. 观察角色：用来理解市场的股票，例如高度、容量、弹性和风险代表。
2. 交易机会：在特定目标和模式下值得深入验证的假设，可能尚未形成买点。
3. 参与计划：已补齐触发、价格范围、失效、退出、预算、时效和规则版本；盘中仍需最新报价与账户检查。

“机会重要”可以与“暂不可执行”同时成立。不能因暂时不可下单将其从机会池中删掉，也不能把机会池第一名直接当成订单。

### 状态词典

- DATA_GAP：缺少必需证据。原因要具体，派生补证任务，不填写估计支撑价。
- WATCH：值得观察，尚未形成明确适用结构。
- WAIT_SETUP：模式已选，等待所需结构。
- WAIT_TRIGGER：结构与条件已经明确，等待触发；完整度仍须按合约核对。
- PLAN_READY：预案字段、批准版本、证据时点和风险预算均齐备；不等于已触发或立即下单。
- SIGNAL_CONFIRMED：在标明的盘中快照时点，触发已确认，仍需独立执行风控；静态报告不能长期维持“现在可以买”的表述。
- REJECT：某一模式/版本明确不通过；必须附条件，不等于股票所有机会消失。
- EXPIRED：计划过期；重新建立版本，不延长旧计划为推荐辩护。

报告中的order_enabled始终为false。本模板是只读分析与显示端，不是交易授权系统。

## 三、精华版：一眼回答五个问题

建议桌面2–3屏、手机分块阅读。这是设计目标而非强制字数限制。

### 1. 首部结论

回答“市场支持什么参与方式？今天最重要的变化是什么？有哪些影响参与的缺口？”

首部同时展示交易日、目标观察日、数据/知识截止、前向冻结状态、数据覆盖。状态日期不能默认由系统当前时间代替。下一交易日必须来自输入的交易日历。

禁止只写“偏多、注意风险”。要具体说明哪些策略场景得到支持，哪些尚不能验证。

### 2. 最重要的0–2项

完整预案存在时，展示0–2项参与计划：股票、模式、理由、触发、最高允许价、结构失效、退出、风险预算、期限、反证。

没有合格计划时，明确显示“0项预案齐备”，并展示最重要的补证/跟踪任务。标题必须是“优先核验”，不能写成“买入推荐”。

不强制每天凑足两只。也不能通过无限增加保守要求，让所有机会永远处于等待：需记录等待原因、解决数据缺口的时限，并在后续检验是否出现模式漏评或无效过滤。

### 3. 持续跟踪与替代比较

所有用户指定股票、实际持仓、活跃计划不得被精华卡限额删除。每只保留：原理由、今日变化、当前状态、下一检查、失效、有效期。

当从A改选B时，必须明确：比较目标、期限、预算、B的优势、A被否决的是哪一条规则、双方缺失、比较何时失效。仅成交额/市值/知名度不同，不足以形成替代结论。

### 4. 条件分支与风险

强势延续、局部分化、整体转弱分别列证据、允许动作、禁止动作。不给未校准的上涨概率。

首页直接列影响决策的重大缺口/冲突。不能把“未核验”的提示藏在很长的附录里。

## 四、细化版：七步顺序不变，增加可审查的解释链

每节输出：可观察事实 → 时间/同类比较 → 解释 → 反证/未知 → 结论 → 下一步核验。这是审计友好的分析说明，不要求保存或展示模型隐藏思维过程。

|步骤|第一段|第二段|第三段及重点|
|---|---|---|---|
|1 市场情绪|广度、涨跌停、炸板，分子分母|昨日涨停池开盘/昨收、收盘/昨收、收盘/开盘|比较5日与20日；先手与后手不同，不能把最高涨幅当收益|
|2 连板梯队|高度、数量、题材内层次|冻结母池晋级/失败/不可核验|高位失败者的入场视角损失、修复与传导；小样本不当胜率|
|3 板块结构|标签并集去重、广度、密度、成交|高度/容量/弹性/跟随/反证成员|业务与当日驱动分开；主线持续、带动关系要有时序|
|4 资金与价格|成交前20的变化与收盘质量|披露资金的单日/多日与去重|量与价格进展是否匹配；成交额不等于净流入|
|5 亏钱效应|风险事件及分层|高开买入、冲高追入的不同损失|看连续收敛/扩散；事件交叉不重复算股票数|
|6 风向标与机会|5–8市场标杆及所有必保留股|三模式适用性、同目标替代比较|原计划状态、下一事件、未采集证据；不能只选容量股|
|7 次日计划|情景分支|个股完整合约|哪条条件触发就核验/参与，哪条使计划过期或失效|

附录A：昨日预案兑现、实际持仓与委托、错误归因。未提供账户记录不能显示账户空仓。

附录B：分析修订、AI数据清单、原来源覆盖与待验证。

附录C：口径冲突、源ID、原始行/字段、快照哈希、公开/可用时间。

## 五、按模式评估，而不是把全部条件堆成总分

### 强势确认

源材料包含一进二、修复涨停和首阴企稳的思路。V2补充“强势延续”的研究接口，不能将其伪装成原文已有的成熟完整策略。

需要检查：相对强度、量价进展、位置与失效距离、同类响应、触发事件、封板/回封与可成交性、完整退出合约。高涨幅不自动排除，强势也不豁免风险。

尚未批准的子模式：仍可进入机会研究和影子记录，但不能升级为PLAN_READY。错过事后上涨不构成越过该边界的理由。

### 趋势回踩

使用足够历史日线、趋势/支撑依据、回踩结构、缩量口径、重新转强与失效。缺回踩只表示此模式尚未满足，不否定强势确认模式。

不能为了一律等待更便宜的价格，而临时改变原模式；也不能在下跌中将“接近支撑”直接等同“获得承接”。

### 尾盘隔夜

保留原材料的八步与下一交易日早盘退出。3%–5%、换手5%–10%等是该来源参数，不能作为全局强势股门槛。14:30只能使用当时已经得到的信息。

所有来源中的模糊阈值、例外和交易结论均保留待验证。原“量比1%”和“金叉对象”不由程序擅自补词。

## 六、机会比较的正确输入

- 目标与期限：同样研究下一交易日、数日趋势或隔夜，不把一个慢波段与另一个盘中弹性直接比较。
- 强度：原始涨幅、同交易板块/同类/同波动组的相对表现、多日延续、分歧日恢复。
- 结构：事件链、突破来源、失效证据和ATR等尺度下的距离；算法与参考窗口必须冻结。
- 容量：成交金额、深度、预计订单相对容量、可成交性；它是约束，不是上涨收益的替代变量。
- 风险：预定失效距离、跳空与无法退出的压力情景、当前账户集中度；不能只看波动小。
- 路径：买点是否会出现、出现时可接受价格在哪里、触发是否太晚，不能以事后最高点补票。
- 证据完整性：相同必需字段；未知为未知，重要机会优先补证。

本版不引入未经校准的“AI胜率”“预计明日涨幅”或武断加权总分。已有经过验证的模型可以输出校准后概率、样本量和误差范围；没有就保持空白。

## 七、误判闭环：改流程，不事后挑赢家

把判定分为四层：机会发现是否漏掉 → 排序/模式是否偏离目标 → 触发和执行是否按时 → 收益是否符合长期样本。

必须分清：本来有可接受买点却漏掉；股票涨了但从未提供合格买点；触发后买不到；价格超限而合理放弃；数据或授权不足而合理阻断。不能把这五类全部算成漏赚。

相同复盘时点比较A/B后续表现，固定观察终点。盘中未结束时不宣布全日结论；最高价只作事后路径描述。净收益比较要纳入实际费用、成交约束与风险尺度。

V2与旧版进行前向影子对照，保留全部被筛掉的高强度候选，抽样展开原始数据检查压缩误杀。指标包括机会覆盖、规则内可执行捕获、误拒绝、风险尾部、AI延迟、平均有效上下文和人工核验成本。样本量不足时不声称收益改善。

## 八、来源与新增内容的区别

原材料组织：每日复盘七步；量价位；角色；回踩/确认/隔夜；风险、内外盘与滞涨；等待和退出。

本次新增：机会与许可分栏、目标约束、对称比较、强势延续研究分支、分层数据包、双层同源渲染、状态契约、误判分类与验证。原观点未因页面更漂亮而被验证。

实际演示全部市场数字来自用户9月21日材料。9月22日用户反馈只作为改进触发，不进入9月21日事实或前向预测。原报告和逐股数据保留在evidence目录供回查。
