# AStockV2: 大富翁系统的证伪台

本目录是 `D:/AICode/Astock`(v1 生产与研究工作区)的验证层。
v1 负责发现、复盘、报告; 本目录负责回答一个 v1 回答不了的问题:

> **一条规则到底有没有可重复的优势?**

项目说明里的目标是把 10 万元在 2 到 3 年做到 1 亿元。这是一个进取愿景,
不是预期收益。愿景要靠**可重复的交易优势**累积, 复利只负责把交易结果放大。
所以每一项改动都必须能回答"这是不是优势", 而不是"这是不是更多发现"。

## 当前状态

**验收裁决: 不通过。** 见 `docs/核心问题诊断与验收结论_20261120.md`。

用 v1 自己冻结的 159 笔成交 (2024-2026, 接受基线 A + 抗跌排序 B),
在与 v1 相同的成交假设下重跑后:

| 检验 | 结果 |
| --- | --- |
| 退出规则是不是太紧 (试 9 种) | 不是。止损从 2ATR 放宽到 4ATR, 胜率 21%->41.5%, 合计盈亏 -3.6 万 -> -9.2 万 |
| 两席排序是不是没挑出好股票 | 不是。同池未选中的候选平均每笔 +0.008%, 实际选中的 -1.388% |
| 信号本身有没有优势 | 没有。同一只股票换一个随机交易日入场, 平均每笔 +1.004% vs 实际 -1.388% |
| S4 是不是更成熟所以更好 | 形态有效, 择时无效。5,403 笔重跑, 比同股异日安慰剂差 -1.100%, 区间 [-1.616%, -0.578%], 显著 |

也就是说: **不是卖得太早, 不是排序不行, 是信号在扣费后没有优势。**
S4 那一条要说得更准: **S4 的绝对收益是正的** (平均 +0.546%/笔), 问题是
它的**入场时点不值这个钱** —— 比同一只股票随机某天买还差 1.1%/笔。
形态分类器是有效的, 失效的是"启动当天开盘就买"这个动作。

按市场环境分层后多出一条**重复性最强的结论**: 在核心指数中期上行的环境里,
S4 追启动日开盘系统性差约 1%/笔 (分环境的"信号 - 安慰剂"差值在 27 组参数
里全部为负、全部显著); 在指数下行的环境里反而更好, 但那只有 3-4 段独立
行情, 去掉 2026 年 4 月一段就不成立。
详见 `docs/市场环境分层与入场时机_20261120.md`。

**这条结论已经落到 v1**：`D:/AICode/Astock/mainwave_engine/index_trend.py`
(核心指数中期趋势环境门) 已接入 S4 扫描，被拦下的候选全部列在"已排除"并
注明原因。实施说明见 `D:/AICode/Astock/S4中期趋势环境门_实施说明_20261120.md`。

## 包结构

```
astockv2/
  config.py     路径与成本常量
  bars.py       本地日线归档读取, ATR20 / 10 日低点 / 涨跌停幅度
  execution.py  统一成交模型: 次日开盘入场, T+1, 跌停锁死顺延,
                分批止盈, 移动止损, 滑点, 费用
  diagnose.py   逐笔路径分解与失败模式归类
  exit_lab.py   退出规则实验台
  control.py    安慰剂对照
  features.py   特征表与分位比较
  verdict.py    验收裁决 (阈值写死, 看结果之前定)
  s4_arm.py     S4 独立验收
```

## 几条硬规矩

1. **成交模型只有一份。** `execution.py` 是唯一的撮合实现, 实验和对照组共用,
   避免"两个实验的差异其实来自成交口径"。
2. **退出规则实验必须先过基线复现。** `run_exit_lab.py` 第一步就是拿
   `structure36_20` 逐笔对账 v1 账本 (当前: 离场日 98% 一致, 原因 99% 一致),
   对不上就不往下走。
3. **验收阈值写在代码里, 不允许事后改。** `verdict.py` 顶部就是判据。
4. **同一天的多笔交易不能当独立样本。** 所有区间用按交易日分块的 bootstrap。
5. **只读 v1。** 研究产物写在本目录, 不碰 `D:/AICode/Astock/results`。

## 下一步该做什么

不是"再加一条发现路径", 而是:

1. **把 `run_verdict.py` 接到每日流水线。** 让每一个新规则先过安慰剂对照,
   过不了就不占名额。这是本目录存在的唯一理由。
2. **把漏失审计从"系统有没有记录突破尝试"改成"信号日之后还会不会涨"。**
   前者是自证式的覆盖率指标, 后者才是可证伪的问题。
3. **把注意力收到入场时机与价格上, 不是选股方向上。** 亏损单的持仓期最大
   浮盈中位 +0.85R, 与随机游走对称, 说明方向判断不构成优势。
4. **硬止损、风险敞口、资金上限一概不动。** 没有任何证据支持放宽它们。
5. **ETF 在个股验收门通过之前, 不要与个股共享风险预算。**
